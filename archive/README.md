# Scientific archive

The repository release carries the reusable scientific archive. Download it from
the [v0.2.0 release](https://github.com/blevlabs/fruit-fly-lab/releases/tag/v0.2.0)
and extract it at the repository root. The attached checksum file verifies the
archive; the file inventory records original and published hashes, classification,
source terms and any privacy-preserving export.

This archive retains numerical traces, reference inputs/code, anatomical source
material, failed and successful studies, and scientific state from completed
experiments. Its historical directory names preserve the connection to the
research reports. Use the current `runtime/` for new work and write new outputs
under `runs/`.

Keys, credentials, private addresses, machine configuration, outbound requests,
operational resource records and personal Git history are excluded. Original
compressed operational bundles are not redistributed. Material without
established redistribution rights is identified by its public source instead.

When checkpoint environment descriptors are removed, the numerical array members
remain unchanged and the inventory labels the file as a scientific-state export.
It is not silently treated as a directly restorable individual. Exact operational
restore still requires the matching source/data/runtime/schema contract.

The [selected results](../results/README.md), [research index](../docs/research/README.md)
and [data guide](../data/README.md) explain what each study establishes. No archived
result closes an unpassed biological or capability gate.

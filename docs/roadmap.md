# Research roadmap

The intended biological system is an adult male fly with supported physical,
sensory, neural, neuromuscular and internal-state mechanisms. A successful motion
video alone is not physiological validation. Later engineered adaptive extensions
remain separate claims. No completion date is supported by the current evidence.

| Milestone | Current boundary | Remaining acceptance |
|---|---|---|
| M0: control and inventory | Complete for the recorded baseline | Maintain reproducible source/data identities and explicit exclusions |
| M1: peripheral correspondence | Partial | Resolve required targets, output topology, fiber allocation and outside-selector systems |
| M2: mechanics/internal state | Implemented estimates and bounded references | Independent motor-to-force calibration and required body/organ mechanisms |
| M3: sensory transduction | Partial modalities | Supported per-organ/per-cell observations and measured response laws |
| M4: central physiology | Lumped approximation | Supported receptor effects, dynamics, modulation and electrical coupling |
| M5: natural repertoire | No accepted full repertoire result | Held-out biological comparisons and causal controls for every required behavior |
| M6: persistence/isolation | Complete for presently implemented state | Extend the schema whenever learned or structural state is added |
| M7: persistent learning | Isolated reference only | Acquisition, recall, restore, reversal, transfer and continued learning |
| M8: prediction/uncertainty | Planned | Learned prediction and useful uncertainty-dependent decisions under controls |
| M9: structural change | Planned | Safe identity/state changes and demonstrated benefit after a capacity limitation is measured |
| M10: heredity/evolution | Planned | Reproducible inheritance/evaluation and controlled improvement in within-life learning |
| M11: communication | Planned | Learned information transfer, then separately tested composition, partners and cultural effects |
| M12: reproduction/closure | Open | Fresh reconstruction and result-by-result support for every claimed capability |

M5 includes posture/righting; locomotion and attachment; jumping/takeoff;
flight/landing; grooming; feeding, swallowing, salivation and elimination;
environmental/internal reactivity; male courtship/reproductive actions; and
rest/endurance. None may be silently replaced with an easier behavior.

## Next scientifically useful step

The selected next reference is the adult 81A07 fast tibia-flexor
spike-to-probe-displacement assay. Its raw anchor trial, units/processing
provenance, independent uncertainty and necessary controls remain unavailable in
the retained work. The [specific data decision](research/next-biological-mechanism-decision.md)
records the preparation, frozen holdouts, readouts and limits.

Obtain a provenance-complete input packet, admit its metadata, then test the
smallest causal reference. A successful female restrained-foreleg reference would
still require exact motor-unit/geometry correspondence and transfer justification
before assignment to the adult male model. Additional numerical cohorts cannot
replace those measurements.

Integrated learning needs calibrated inputs, consequences and motor pathways for
its chosen task. It need not wait for every unrelated peripheral gap, but it
cannot close the full-fly requirements. Communication can branch after persistent
learning; evolution is not its prerequisite. Reuse the existing runtime and
checkpoint contract instead of prebuilding population or growth infrastructure.
